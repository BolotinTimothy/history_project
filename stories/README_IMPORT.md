# Готовые истории для импорта

В этой папке 25 JSON-файлов историй. Все этапы переписаны так, чтобы повествование было обращено к пользователю, а варианты выбора отвечали на вопрос бота «Что вы сделаете?».

Формат совместим с текущим импортёром проекта: обязательные поля сохранены, дополнительные поля с источниками остаются в JSON как редакторская справка.
